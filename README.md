# Horizon Support — modern HTML site

Static HTML rebuild of horizonsupport.com.ng (study-abroad consultancy for Nigerian students).

Mobile fixes, 2026-11-13: subtler mobile menu highlight (gold left bar, no blue block), fewer boxed cards (contact ways, room types, document checklist, country and city rows sit on the background), mobile text-overflow fixes (city grid goes single-column under 600px, grid children can shrink and wrap), and swipe cues on tab rows (fade at the cut-off edge plus a Swipe hint while more tabs are off-screen).

Serve the folder as-is. No build step, no backend. Forms hand off to WhatsApp / email.
